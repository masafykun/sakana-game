# SakanaGame 🐟

An underwater WebGL game that runs in the browser. **Every line of the game code was generated by [Sakana AI](https://sakana.ai)'s Fugu Ultra orchestration model** — a single prompt in, one self-contained `index.html` out.

![gameplay](screenshots/gameplay.png)

## Play

- **Live:** https://masafykun.github.io/sakana-game/
- **Local:** clone and open `index.html`, or `python3 -m http.server` then visit `http://localhost:8000`

No build step, no dependencies to install — Three.js is loaded from a CDN and the whole game is one HTML file.

## Controls

- **Move:** mouse / touch to follow, or `WASD` / arrow keys
- **Goal:** eat the drifting food to raise your score and grow
- **Avoid:** the larger fish — contact ends the game

## How it was generated

The game was produced in a single call to Sakana AI's `fugu-ultra` model through its OpenAI-compatible API. Fugu is a learned multi-agent orchestration system: one request is fanned out across a pool of frontier models, verified, and synthesized into a single answer.

| Item | Value |
| --- | --- |
| Model | `fugu-ultra` |
| Generation time | ~864 s (≈14.4 min) |
| Total tokens | 113,995 (final output ≈14k; the rest is internal orchestration) |
| Output | single 30 KB `index.html` |

The exact prompt is in [`tools/gen.mjs`](tools/gen.mjs), the generator harness used to call Fugu and save the result.

## Tech

- [Three.js](https://threejs.org/) `0.160.0` (ES modules via import map)
- Pure procedural geometry, shaders, and lighting — no external assets
- Single-file, mobile and desktop, resize-aware
